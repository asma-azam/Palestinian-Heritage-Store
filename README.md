# Palestinian Heritage Store

## Project Overview
A full-stack e-commerce web application developed as part of a university Web Development course at Birzeit University.

The website showcases Palestinian heritage products and provides shopping and product management functionality.

## Technologies Used
- HTML & CSS
- PHP
- MySQL
- SQL
- XAMPP
- Visual Studio Code

## Main Features
- User registration and login
- Product listing and product details
- Add, edit, and view products
- Shopping basket management
- Checkout functionality
- Database integration using PHP PDO
- User sessions and logout

## How to Run
1. Install XAMPP.
2. Copy the project folder into `xampp/htdocs/`.
3. Start Apache and MySQL.
4. Import the included SQL file using phpMyAdmin.
5. Configure the database connection in `dbconfig.inc.php`.
6. Open the application through `http://localhost/assThree/`.
